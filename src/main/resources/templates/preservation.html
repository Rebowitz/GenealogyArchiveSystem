Unresolved objects

Objects at archive locations that the archive cannot identify as its own copy. They are never moved or deleted automatically. Inspect each on its volume, then attest that it is the archive's copy (it is moved to quarantine, or removed by a pending destruction, only while it is still exactly the object recorded: same size, SHA-256, file times and file key where the system has one) or release it as not the archive's (it stays where it is). Objects recorded before identity evidence was kept cannot be attested; release them.
